# `release/v1.12.0` — стабилизация недельного релиза

Ветка создана от `develop` после объединения трех feature-команд. Новые функции заморожены. Допускаются исправления дефектов, обновление документации и подготовка версии.

Обязательные проверки: импорт товара, синхронизация остатков, резервирование товара, создание платежа, обработка уведомления, регрессионные тесты, SAST и проверка зависимостей.

После успешного тестирования ветка сливается в `main`, коммит получает тег `v1.12.0`, затем release сливается обратно в `develop`.
