# `hotfix/v1.12.1` — срочное исправление production

Ветка создаётся от стабильного `main` (релиз v1.12.0), если обнаружена критическая проблема. В примере исправляется обработка повторного уведомления от платежного провайдера: повторный callback не должен приводить к повторному списанию.

После исправления добавляется регрессионный тест, выполняются code review, SAST и проверка зависимостей. Затем ветка сливается в `main` и `develop`, а стабильный коммит получает тег `v1.12.1`. При наличии активной release-ветки исправление переносится и туда.
